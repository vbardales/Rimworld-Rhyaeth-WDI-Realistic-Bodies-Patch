# Rhyaeth WDI Realistic Bodies Patch

A compatibility patch: the Rhy'aeth xenotype of Erin's Rhy'aeth wears the scaly body textures of
WDI's Realistic Bodies (the `ScalySkin` set), body type by body type, for the latest RimWorld version.

Status: the patch is written (`Mod/Patches/RhyaethScalySkin.xml`) and tested in game; not published yet. Design notes: `Docs/NOTES.md`.

Requires Erin's Rhy'aeth (`Erin.Rhyaeth`) and WDI's Realistic Bodies (`WDI.Realistic.Bodies`).
